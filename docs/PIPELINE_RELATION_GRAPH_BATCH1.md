# PIPELINE-RELATION-GRAPH-BATCH1 · 加工链多表关系可视化（2026-10-16）

## 本批交付

基于现有数据加工编辑器首步 JOIN/UNION 的服务端已有限制的能力，新增只读的“数据模型关系”面板。**没有新增 JOIN SQL 构造器、后端 API、数据库元表或第三套设计器**，也未将已存在的单次 JOIN/UNION 包装为任意多表模型能力。

- 关系概览读取现有已授权的数据集名称、字段目录和正在编辑的 JOIN / UNION 步骤配置，显示主数据集 → 关联/合并数据集，以及 LEFT/INNER JOIN 或上下合并方式。无关系步骤时不显示虚假节点。
- 在有显式关联键或上下合并字段映射时，分别列出左/右稳定字段 ID 对应的可读名称，并明确标记类型不一致/字段缺失；JOIN 展示右表投影数和**直接引用这些投影字段**的下游步骤数量。
- 若未确认可能的 JOIN 行数放大，则显示警示；UNION 未配置对应字段时明确说明将依赖服务端编译检查。面板可折叠、键盘可操作，视图变化由当前 `steps[]` 实时重新生成，不维护独立的第二份模型事实。
- 这些警告只是 UI 预览，不替代服务器已经存在的 `AnalysisPipelineCompiler.join/union`、同连接约束、字段权限、行数风险确认或发布版本判断。不会把 SQL、本地预览值或敏感连接配置展示给无权用户；该页面仍在已有管理员的数据加工入口下。
- 目前仅支持已实现的一次同连接 JOIN/UNION 加工关系概览（无需数据库迁移），不代表任意 N 张表关系建模、跨连接查询、维表血缘管理或自助关系图拖动生成 SQL 已完成。
